# pairwise-terrain-splat-blend

山坡上草地和岩石的交界出现一条硬线，四层 splat 权重相加不等于 1，归一化只做了前三层；混合顺序按贴图槽位固定，岩石层被草地反复覆盖；平铺纹理在边界处没有做无缝处理，接缝处出现一条亮线；法线贴图按权重线性混合后没有重新归一化，交界处光照塌陷；远处用了高层级 mip，细节层先被抹平，草地纹理延伸到岩石上；权重压成 8 位，四层各占 25% 时精度只剩两档，过渡出现台阶；高度混合只比较高度差，没有考虑斜率，陡坡上岩石盖不住草地；三平面映射在斜坡上没有按法线权重混合，纹理被拉成条状；阴影通道采样了另一套 splat，阴影里的材质和可见材质不一致；细节贴图没有随距离衰减，远处地面全是高频噪点。render/terrain_splat_blend.py 是核心，tests/test_terrain_splat_blend.py 15个红。要修的是：权重归一；按层排序；无缝平铺；法线重算；mip 一致；16 位权重；高度加斜率；三平面混合；阴影同套权重；细节随距离衰减。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
